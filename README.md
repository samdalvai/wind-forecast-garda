# Wind Forecast Garda

Small React app for wind forecast on Lake Garda, Italy. It shows the forecast pressure difference between Brescia/Ghedi and Bolzano, fetching Open-Meteo pressure data and rendering a simple chart with daily separators, threshold lines at `-2` and `2` hPa, and highlighted areas when the difference exceeds those thresholds.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Check code

```bash
npm run lint
```
